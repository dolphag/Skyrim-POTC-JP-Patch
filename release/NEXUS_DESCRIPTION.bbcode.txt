[url=https://www.nexusmods.com/skyrimspecialedition/mods/196635]Path of the Companions[/url] 1.0.0 を日本語化するパッチです。原作がメッセージを外部のテキストファイルに分けて読み込んでいるので、その日本語版を置きます。DLLは変更しません(ファイルを置くだけです)。

日本語対応フォントを同梱しています(原作のテーマ用フォントを置き換えます)。詳しくは「日本語フォント(同梱)」を参照してください。

[b]必須[/b]
[list]
[*][url=https://www.nexusmods.com/skyrimspecialedition/mods/196635]Path of the Companions[/url] 1.0.0 本体と、原作の必須ファイル POTC Effects 1.0.21 以上[/*]
[*]SKSE Menu Framework 3 で日本語を表示するための日本語フォント設定。
日本語環境を導入済みなら追加の設定は不要です。私は [url=https://skyrimspecialedition.2game.info/detail.php?id=120352]2game 様の日本語化ファイル[/url]で動作を確認しています。[/*]
[/list]

[b]日本語フォント(同梱)[/b]
原作の画面は、日本語の字形を持たないテーマ用フォントで描かれるため、そのままだと日本語が「?」になります。本パッチには、同じ名前の日本語対応フォント(Noto Sans JP を元にしています)が入っていて、原作のフォントを置き換えます。英字の見た目も、このフォントに変わります。
優先順位は 本体 → 本パッチ の順にして、フォントが原作のフォントに勝つようにしてください。
自分のフォントを使いたい場合は、本パッチの SKSE/Plugins/Fonts/ の3つのファイルを無効にし、日本語対応の TTF を同じ3つの名前で置いてください。
Fight With Me の日本語化パッチにも同じフォントが入っています(同一のファイルなので、両方入れても問題ありません。上書きの確認が出たら、どちらを選んでも同じです)。

[b]推奨[/b]
[list]
[*]姉妹MODの日本語化パッチ: [url=https://www.nexusmods.com/skyrimspecialedition/mods/194872]Walk With Me - Japanese Translations Patch[/url][/*]
[/list]

[b]Fight With Me を併用する場合(任意)[/b]
Path of the Companions は [url=https://www.nexusmods.com/skyrimspecialedition/mods/194766]Fight With Me[/url] がなくても動きます。併用するときは、Fight With Me 用の日本語化パッチ([url=https://www.nexusmods.com/skyrimspecialedition/mods/194874]Fight With Me - Japanese Translations Patch[/url])も入れてください。バトルプランなど、Fight With Me の画面が日本語になります。
本パッチの訳にも Fight With Me の画面の文言の大部分が含まれているので、両方入れても問題ありません。

[b]バージョンについて[/b]
本体と本パッチのバージョンは必ずあわせてください。バージョン番号は原則として本体と同じです。
同じバージョン内でパッチだけを修正したときは、x.x.x-1 のように枝番をつけます。

[b]導入[/b]
MOD として入れてください(MO2・Vortex など)。優先順位は 本体 → 本パッチ の順にして、同梱のフォントが本体のフォントに勝つようにします。
DLL・INI・セーブには影響せず、無効化すれば元に戻ります。
本体を更新するときは、本パッチを外す必要はありません。ただし、新しく増えた文言は英語のまま表示されます(パッチの更新をお待ちください)。

[b]日本語にならないとき[/b]
言語はゲームの設定(Skyrim.ini の sLanguage)に従います。JAPANESE のときは FightWithMePaths_JAPANESE.txt、ENGLISH のとき(英語版ゲームのまま日本語化している環境など)は、同じ内容の FightWithMe_JA_Paths_ENGLISH.txt が読まれます。どちらも、ファイルを置くだけで日本語になります。
それ以外の言語名(FRENCH など)のときは、[b]SKSE/Plugins/FightWithMePaths_user.ini[/b] に次を書いてください(無ければ新規作成。ゲームの再起動後に反映されます)。Fight With Me も使う場合は、[b]SKSE/Plugins/FightWithMe_user.ini[/b] にも同じ内容を書いてください(DLL ごとに別々に読みます)。
[code][Interface]
sLanguage = JAPANESE[/code]
この設定が効くのは、Path of the Companions の画面の文言だけです。SKSE Menu Framework 全体や、ゲーム本体の言語、魔法名などのゲーム由来の文字列には影響しません。
SKSE のログ(Documents/My Games/Skyrim Special Edition/SKSE)に「[Text] JAPANESE: N lines from ...」(ENGLISH のときは「[Text] ENGLISH: ...」)と出ていれば、日本語のファイルは読まれています。

[b][color=#ff0000]魔法名などが「?」になるときは？[/color]
[/b]魔法名や従者名など、ゲームや他のMODから取得する文字列に？が入って表示されないことがあります。
SKSE Menu Framework の日本語グリフ範囲の制限があり、この範囲外の漢字( 靭・怯・罠・痺など)があると「?」になります。(SMF側に修正依頼を投げているところです。)
気になる場合は、SKSEMenuFramework.ini の [Fonts] で
[code]EnableChinese = true[/code]
を設定してみてください(SMF v3.18 以降で追加された項目)。元々の EnableJapanese = true はそのままで。
私の環境では、日本語範囲では「?」になる漢字が、この設定では表示されることを確認しています。
(EnableChineseを有効にしても使用するフォントがNotoSansJPであれば、いわゆる中華フォント状態にはなりません。）

[b]日本語になるもの / ならないもの[/b]
ツリー画面(各ツリーのアビリティ・分岐・特性・ランク・ボーナス・ガイド)、設定ページ、通知メッセージが日本語になります。

[*]パーティ設定ページの、役割・注目対象・位置取りのドロップダウン(選択肢と、その説明のホバー表示)は、Fight With Me と共通の画面で、原作のこの部分がメッセージのファイルを通していないため、英語のままです(原作側の修正が必要です)。[/*]
[*]テーマ名(Vanilla / Oxblood / Nordic)は、原文のままにしています。[/*]
[*]キー名・ボタン表示、ログ、INIのコメントは変更できません。[/*]
[/list]
「スキル」は、バニラのスキルと混同しないよう、「アビリティ」に統一しています。
新しいアビリティ名(ケイオスダウン、最後の砦、風渡り、爆裂矢 など)は意訳を含み、一部は暫定です。ご意見があればコメントでお知らせください。

[b]English[/b]

An unofficial Japanese translation patch for [url=https://www.nexusmods.com/skyrimspecialedition/mods/196635]Path of the Companions[/url] 1.0.0. The original keeps its messages in external text files; this patch is the Japanese version of those files, so no DLL is changed (just a file to place).

A Japanese-capable font is included (it replaces the original's theme fonts); see "Japanese font (included)" below.

[b]Requirements[/b]
[list]
[*][url=https://www.nexusmods.com/skyrimspecialedition/mods/196635]Path of the Companions[/url] 1.0.0 and POTC Effects 1.0.21 or newer (required by the original)[/*]
[*]A Japanese font set up in SKSE Menu Framework 3.
No extra setup is needed if you already have a Japanese environment. I tested with the [url=https://skyrimspecialedition.2game.info/detail.php?id=120352]Japanese localization by 2game[/url].[/*]
[/list]

[b]Japanese font (included)[/b]
The original draws its screens with theme fonts that have no Japanese glyphs, so Japanese would show as "?". This patch includes a Japanese-capable font under the same names (based on Noto Sans JP) that replaces the original's fonts. Latin letters will look different too.
Mod order: original -> this patch, so the font wins over the original's fonts.
To use your own font, disable the three files in SKSE/Plugins/Fonts/ of this patch and put a Japanese-capable TTF under the same three names.
The Fight With Me Japanese patch contains the same font (identical files, so having both is fine; if you are asked to overwrite, either choice is the same).

[b]Recommended[/b]
[list]
[*]Sister patch: [url=https://www.nexusmods.com/skyrimspecialedition/mods/194872]Walk With Me - Japanese Translations Patch[/url][/*]
[/list]

[b]If you also use Fight With Me (optional)[/b]
Path of the Companions works without [url=https://www.nexusmods.com/skyrimspecialedition/mods/194766]Fight With Me[/url]. If you use both, install the Fight With Me patch ([url=https://www.nexusmods.com/skyrimspecialedition/mods/194874]Fight With Me - Japanese Translations Patch[/url]) too, so its own screens (battle plan, ...) are translated.
This patch already contains most of Fight With Me's screen texts, so having both is fine.

[b]Versions[/b]
Use the patch version that matches your Path of the Companions version. Version numbers follow the original mod.
If the patch alone is fixed within the same version, a suffix such as x.x.x-1 is added.

[b]Install[/b]
Install as a mod (MO2, Vortex, ...). Mod order: original -> this patch, so the bundled font wins over the original's fonts.
No DLL, INI or save is touched; disabling the patch restores the original.
When the original updates you do not have to remove this patch, but new texts stay in English until the patch is updated.

[b]If it stays English[/b]
The language follows the game (sLanguage in Skyrim.ini). FightWithMePaths_JAPANESE.txt is read when it is JAPANESE; FightWithMe_JA_Paths_ENGLISH.txt, a copy of the same content, is read when it is ENGLISH (an English game that was Japanized, for example). Either way, just placing the files is enough.
For any other language name (FRENCH, ...), add this to [b]SKSE/Plugins/FightWithMePaths_user.ini[/b] (create it if missing; restart the game). If you also use Fight With Me, put the same in [b]SKSE/Plugins/FightWithMe_user.ini[/b] (each DLL reads its own):
[code][Interface]
sLanguage = JAPANESE[/code]
This setting only affects the texts of Path of the Companions's own screens. It does not affect SKSE Menu Framework as a whole, the game's language, or strings that come from the game (spell names, ...).
The SKSE log should show "[Text] JAPANESE: N lines from ..." (or "[Text] ENGLISH: ..." in an English setup) if the files were read.

[b][color=#ff0000]Question marks in spell or companion names?[/color][/b]
Strings that come from the game or other mods can show "?" for kanji outside the Japanese glyph range of SKSE Menu Framework. If it bothers you, set [code]EnableChinese = true[/code] under [Fonts] in SKSEMenuFramework.ini (SMF v3.18+), keeping EnableJapanese = true. With a NotoSansJP font this does not give a Chinese-looking face.

[b]Translated / not translated[/b]
The tree screens (abilities, branches, traits, ranks, bonuses, the guide), settings pages and notices are translated.
[list]
[*]The role / focus / position dropdowns on the Party settings page (the choices and their hover tooltips) stay in English. This screen is shared with Fight With Me, and the original does not read these texts from its external message files, so it needs a fix on the original's side.[/*]
[*]Theme names (Vanilla / Oxblood / Nordic) are kept as in the original.[/*]
[*]Key names, button labels, logs and INI comments cannot be changed.[/*]
[/list]
"Skill" is rendered as "アビリティ" (ability) to avoid confusion with vanilla skills. Some new ability names are free translations and provisional; feedback is welcome in the comments.
